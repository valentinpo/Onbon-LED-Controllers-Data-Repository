	📦 Onbon LED Controllers Data Repository
Репозиторий содержит структурированные данные о контроллерах LED-дисплеев Onbon, собранные с официального сайта onbon.ru. Включает инструменты для обработки, объединения и организации данных.
	📋 Описание проекта
Этот проект представляет собой ETL-пайплайн (Extract, Transform, Load) для сбора и обработки технической информации о контроллерах Onbon. Все данные хранятся в формате JSON и готовы к использованию в веб-приложениях, каталогах или для аналитики.
	🎯 Цели проекта
Централизация: Объединение разрозненных JSON-файлов в единую базу данных.
Стандартизация: Очистка данных от технических ошибок (пробелы в ключах, вложенность).
Автоматизация: Скрипты для создания структуры папок и расширения карточек товаров.
Доступность: Предоставление данных в удобном машиночитаемом формате.

	📁 Структура репозитория
	
onbon_JSON/
├── 📁 controllers/              # Папки с контроллерами
├── 📁 по категориям/            # Группировка по категориям
├── 📄 add_fields.py             # Добавление полей
├── 📄 controllers_list.txt      # Список всех контроллеров
├──  create_folders.py         # Создание папок
├── 📄 get_list.py               # Извлечение списка
├──  merge.py                  # Объединение JSON
├── 📄 merged.json               # Объединённый файл
└──  merged_updated.json       # Финальный файл с полями



	🚀 Быстрый старт
	
Требования
Python 3.8+
Стандартные библиотеки: json, os, pathlib

	Установка и запуск
bash
# 1. Клонируйте репозиторий
git clone https://github.com/your-username/onbon-controllers.git
cd onbon-controllers

# 2. Запустите полный цикл обработки
python src/merge.py              # Шаг 1: Объединение файлов
python src/add_fields.py         # Шаг 2: Добавление полей
python src/get_list.py           # Шаг 3: Получение списка
python src/create_folders.py     # Шаг 4: Создание структуры
